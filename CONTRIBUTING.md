
# Contributing to PhishGuard

Thank you for your interest in contributing!

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test your changes locally.
5. Commit your changes with a meaningful message.
6. Open a pull request describing your changes.

## Branch Naming

- feature/feature-name
- fix/bug-name
- docs/documentation-update

## Commit Message Guidelines

Use clear and descriptive commit messages.

Examples:
- feat: add email risk indicators
- fix: correct email parsing
- docs: update installation instructions
- style: improve analyzer layout
- test: add email validation tests

## Code Guidelines

- Write readable and maintainable code.
- Keep changes focused.
- Avoid committing secrets or personal data.
- Test changes before submitting a pull request.

## Reporting Issues

When reporting an issue, include:
- A clear description
- Steps to reproduce
- Expected behavior
- Actual behavior

Thank you for helping improve PhishGuard!
