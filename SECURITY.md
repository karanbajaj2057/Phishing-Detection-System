
# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in PhishGuard, please report it privately to the project maintainer.

Do not publicly disclose sensitive vulnerability details before a fix or mitigation is available.

## Security Best Practices

- Do not commit secrets or credentials.
- Avoid using real confidential emails in public demonstrations.
- Keep project dependencies updated.
- Validate uploaded files and user input.
- Avoid treating automated phishing classifications as definitive.
- Review security-related changes before merging.

## Scope

This policy applies to the PhishGuard project and its publicly maintained source code.
